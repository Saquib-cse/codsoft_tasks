# CodSoft Internship Tasks

This repository contains the tasks completed as part of the CodSoft internship program.

## Tasks

### Task 1: Student Record Management API
Folder: Student_Record_Management_API

A backend REST API built with Django REST Framework to manage students, courses, and enrollments. Features full CRUD operations, custom validation, search/filter/sort/pagination, and proper HTTP status codes.

Stack: Python, Django, Django REST Framework, SQLite

### Task: Library Management System
Folder: Library_Management_System

A backend system built with Django REST Framework to manage a library's books, members, authors, and issued books. Supports adding, updating, deleting, issuing, and returning books, with validation to prevent checking out unavailable copies. Includes search, filtering, and pagination across books and members, plus a bonus reporting endpoint that calculates overdue days, late fees, and overall library status.

Stack: Python, Django, Django REST Framework, django-filter, SQLite
